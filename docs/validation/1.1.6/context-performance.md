## 持久化路径修复

最终代码保留 call.created、请求载荷、绑定、运行和完成事件，不删除活动记录，也不提高缓存 TTL。活动日志批量追加在同一跨进程锁内分配序号并一次同步日志段；日志尾部是已提交序号的权威来源，旧版本已预留但未写入的序号不会复用。相同载荷在五分钟保护期内只在剩余保护时间不足一分钟时续期，避免每次热调用改写文件元数据。

顺序重放、整批预校验、跨 Store 唯一序号、损坏尾部恢复、陈旧/超前 sequence 状态、载荷续期、调用开始可见、根调用失败和并发调用均有自动化回归。internal/activity race 测试、全仓库 Windows Go 测试和 go vet ./... 通过。
