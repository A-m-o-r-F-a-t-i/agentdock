# AgentDock 1.1.4：显示、观测与 Windows 启动收敛

　　1.1.4 在 1.1.3 的对话／任务执行中心基础上，完成桌面视觉状态、真实调用观测、ChatGPT MCP Apps 显示策略、Tailscale Funnel 等待行为和管理员后台启动的收敛。本文件描述候选源码与验收边界；只有 GitHub Windows Package 工作流成功生成并校验的安装包才是本次可安装交付物。

## 1. Windows 桌面界面

- 按钮、菜单和选择控件在鼠标移开后仍保留默认边框及选中状态，不再依赖 hover 才能判断可点击性或当前模式。
- 浅色、深色与跟随系统主题使用应用级动态资源；主窗口、执行窗口和对话框保持同一套文字、边框、背景和焦点语义。
- 执行记录提供紧凑／详细视图，显示真实工具名、对话／任务标签和真实状态。旧记录没有耗时时显示“未记录”，不再渲染虚假的零耗时。
- 对话侧栏在最近 30 秒内收到真实根工具请求时显示活动标记。列表刷新、SSE 重放、健康检查和后台探测不会续期，终止对话不会继续显示为活跃。
- 菜单显式标记当前筛选和主题选择，移除无意义的回收站分隔线，同时保留键盘焦点、审批、归档、批量操作和右键管理能力。

## 2. 调用观测与文件编辑

| 项目 | 1.1.4 行为 |
| --- | --- |
| 根调用身份 | 每个外部请求只建立一个根调用；内部阶段和子调用继承既有不可变绑定，不创建第二个伪根。 |
| 时间测量 | 分别记录请求接收／返回、RPC 总耗时、处理器执行、等待及命令进程阶段；未知值保持为空。 |
| `file_edit` | replace、patch、add、delete、move 记录动作、路径、dry-run、是否执行、是否改变、受影响文件、增删行和有界 diff。 |
| 参数失败 | 动作级 Schema 在派发前校验必填字段；失败仍进入调用历史，但明确为未执行，不伪造成处理器已执行。 |
| 旧数据 | 可继续读取，不根据更新时间、完成时间或进程状态推测缺失测量，也不回写原始日志。 |
| 脱敏与边界 | 路径、预览和输出在持久化前遵循现有脱敏／截断规则，多文件详情保持有界。 |

## 3. ChatGPT MCP Apps 显示开关

　　控制面板“显示”页新增“提供 AgentDock 内嵌界面”开关，状态持久化到独立显示设置，并通过修订号避免并发覆盖。保存成功后 Core 立即采用新策略，不需要重启服务。

　　关闭后只停止发布 AgentDock 的 UI 资源和工具 UI 绑定；工具列表、结构化结果、文件参数元数据、认证、可见性限制、任务、插件和动态 MCP 保持可用。已在 ChatGPT 中渲染的历史卡片不会被远程删除，需刷新连接并在新对话中验证宿主采用情况。

## 4. Tailscale Funnel

- 将“本机映射已正确应用”和“公网已经可访问”拆成两个阶段，DNS／边缘传播超时不再触发破坏性的整套回滚。
- 状态查询短时缓存，重复点击共享进行中的请求；已存在且完全匹配的 AgentDock 映射直接复用。
- 公网探测可取消并使用有界退避，区分 DNS、TLS／HTTP、认证和成功状态。
- 冲突映射仍失败关闭；停止和回滚只处理仍由当前运行目录拥有的根映射，不调用全局 reset、down 或 logout。

## 5. 管理员后台启动

　　管理员模式的计划任务不再直接启动控制台子系统的 `agentdock.exe service launch-core`。任务改为启动托盘 WinExe 的 `--run-core-task` 入口，再由隐藏窗口、`CreateNoWindow` 和 Kill-on-close Job Object 托管 Core。这样保留管理员 Core、安装回滚和同一 Windows 用户校验，同时避免登录或安装结束后出现可见控制台黑框。

　　安装脚本、WPF 管理服务、Go 契约测试与 PowerShell 验收均使用同一个托盘 Launcher 路径；旧的直接控制台任务动作被专项断言禁止回归。

## 6. 工程约束与迁移

　　仓库根 `AGENTS.md` 固化调用身份、可空测量、UI／服务责任、异步取消、状态边界、测试和仅向用户 fork 交付等规则。实现位置和验收门槛见 [`implementation-1.1.4.md`](../implementation-1.1.4.md)。

　　本分支与上游官方版不是可共享默认状态目录的并装发行线。跨发行线切换时应卸载并清理旧状态，或仅在备份副本中由 AI 辅助转换已复核的文本配置；凭据、审批、执行日志和安装事务不能直接复制。完整说明见[差异与迁移指南](../official-version-differences-and-migration.md)。

## 8. 交付边界

- 目标版本：Core 与 Windows Control Panel 均为 `1.1.4`。
- 目标平台：Windows amd64。
- 目标安装包名：`AgentDock-1.1.4-Windows-x64-Setup.exe`。
- 本次只要求候选构建并下载到本机，不自动创建公开 GitHub Release、标签或覆盖当前生产实例。
- 外部 DNS／Tailscale 边缘传播、真实 ChatGPT 宿主是否立即刷新 MCP Apps UI，以及物理 DPI／多显示器视觉效果仍需在对应真实环境中判断，不能由静态测试代替。
