# AgentDock 1.1.1 — 访问配置、任务展示与接入检查修复

本版仅在 A-m-o-r-F-a-t-i/agentdock 发布 Windows x64/ARM64 资产。当前按验证预发布交付，不替换 1.1.0 的正式发布和旧安装包。真实 ChatGPT 首次授权、工具扫描、刷新与重连尚需单独完成客户端验收，隔离协议回归不代替该项。

## 公网访问页面

- 四种访问模式的专属区域互斥显示，固定域名表单初始折叠，仅在选择固定域名时出现。
- 所选配置草稿与当前生效模式分别显示。刷新保留输入，失败保留域名与替换 Token，只有对应配置应用成功才清理凭据输入。
- 禁止并发应用、重复生成和启停。配置版本变化后忽略过期检查结果。
- Tailscale 主操作统一为“启用并检查”，固定域名 Token 提示仅出现在固定域名区域。

## 任务活动中心

- 概览页增加任务活动中心入口，复用原有单实例窗口；任务数量摘要明确标注最多 200 项的统计范围。
- 待处理、进行中、已结束任务分组。任务状态、步骤进度、下一动作和原因分块呈现，步骤默认展开，内部 ID 移入技术详情。
- 已取消与已归档分别保留，原始 task.completed 标题正确显示取消结果。单一执行分支不显示选择器。
- 增加非消费式实时会话检查。取消任务不会停止进程，界面明确提示当前运行数量，并继续展示已结束任务下仍在运行的命令。
- 停止命令验证具体任务、分支与实际运行状态，不从历史事件推断命令仍在执行。
- 任务工作区按明确绑定解析；未绑定或记录缺失有独立提示。命令目录使用命令实际工作目录。
- 命令复制与停止、文件定位与当前差异操作放在对应记录旁。支持活动类型筛选、历史浏览暂停跟随和返回最新。
- 复制继续或重试指令不启动模型。解除阻塞只恢复对应状态，后续执行由客户端发起。

## Tailscale 与 OAuth 检查

- WWW-Authenticate 按认证方案和参数解析，兼容合法空白、参数顺序、大小写和附加参数，拒绝重复或歧义字段。
- 公网网络错误保留阶段、路径、状态或传输错误与时间。界面匿名检查网络及认证发现，禁止向检查地址附带本地凭据或跟随重定向。
- Funnel 服务端自检覆盖 initialize、初始化通知和 tools/list，仅清理本轮创建的会话。
- 隔离 TLS 回归覆盖 DCR、正常密码授权、PKCE S256、工具定义、OAuth 只读工具调用、非法 Token、持久化 Core 重建和 Token 刷新。
- “网络与认证发现通过”“服务端检查通过”“仍需客户端授权及扫描”分别表达验证范围。未改为无鉴权接入。

## 使用与验收边界

Windows 用户通常选择 AgentDockSetup-amd64.exe，Windows on ARM 使用 AgentDockSetup-arm64.exe。安装包保留现有升级和回滚机制，任务记录结构未迁移。AgentDock 自有二进制未进行 Authenticode 签名，捆绑的官方 cloudflared 仍验证供应商签名。

本版继续使用 WPF 与 Go。批量删除、任务分类管理和新的权限审批模式留在 1.1.2；没有引入模型运行器或自动继续功能。最终构建、安装与客户端验收结果以随发布提供的验证说明为准。
