# AgentDock 1.1.0 — 任务活动中心与 Tailscale Funnel

本版将任务可观测性、可恢复线程、工作区路由和 Windows Tailscale Funnel 合并为同一个 1.1.0。发行目标仅为本仓库的 Windows x64/ARM64，不生成 Linux、macOS 或容器发行资产。

## 任务与执行

- 新增独立任务活动中心，从托盘打开，或使用 `agentdock-tray.exe --activity`。按任务和线程查看真实命令、工作目录、运行环境、输出、退出码、耗时、文件修改、工具调用和阶段检查点。窗口不运行模型，也不展示模型隐藏思维过程。
- 命令、文件编辑、动态 MCP、浏览器和插件调用可绑定 `task_id / thread_id / step_id / workspace_id`。命令会话固定原绑定，后续观察、输入和停止自动沿用，切换默认线程不会改写已运行的会话。
- Thread 支持创建、检查点、切换、阻塞、恢复、分叉与关闭。Task 区分成功和取消，支持归档和解除归档，历史记录仍可查询。取消任务不会隐式杀死命令，应使用独立停止操作。
- 上下文提供最多 8 个、16 KiB 的活动任务索引，保留线程、当前步骤、摘要和下一动作。旧版任务只读加载时映射为 main，首次修改才持久化线程，无需手动迁移。
- 新增 Workspace Registry 和 `source / artifact / scratch / cache / external` 路由。带工作区绑定的写入检查实际路径和越界，外部目标必须显式声明。工作区路由不构成 shell 沙箱，旧版无绑定工具的显式路径保持兼容。
- 启动说明、上下文和统一顶层 `agentdock_guidance` 提供简短的状态相关指导，提醒复用会话、核验最终退出状态和保存检查点。外部工具正文不成为可信 Guidance。

## 本地活动接口

持久活动日志使用有界分段、增量输出合并和写入前脱敏。SSE 支持 Last-Event-ID 重放、重连去重、心跳和连接释放。过期日志被清理时显示缺口提示，不伪装成完整历史。

新增活动流、控制和 Diff 接口只接受直接回环访问，校验本地 Host、Origin、代理头及已配置认证，Cloudflare/Tailscale 公网转发不能读取活动输出。桌面客户端禁止代理和重定向，使用有界队列、虚拟化列表及折叠输出。

活动中心支持停止命令、复制脱敏命令、打开工作目录、定位修改文件、查看当前 Git Diff、线程管理和日志清理。Diff 来自当前已跟踪工作树与 HEAD 的比较，不还原历史文件，也不使用外部 diff/textconv。

## Tailscale Funnel

- Windows 公网访问增加 Tailscale Funnel，自动读取已登录客户端的设备域名，无需 Cloudflare Tunnel Token。继续支持 Cloudflare Quick、Named 与仅本机方式。
- 控制面板增加客户端、设备、域名、密钥到期及 Funnel 状态，提供检测和启停入口。Tailscale 模式隐藏 Tunnel Token，托盘读取当前 provider 的有效公网地址。
- 完整 Origin 转发及就绪验证覆盖 OAuth Metadata、MCP 描述、401 challenge 和认证 initialize。
- 使用精确路径及所有权记录管理映射，拒绝覆盖其他服务或顺带公开私有 Serve 路径。失败后恢复自身配置和原运行状态，卸载保留 Tailscale 客户端和无关映射。
- 安装升级和同版本修复保留 provider、Origin、监听端口和映射所有权记录。

## 兼容与安装

保留 1.0.1 的插件/Skill 管理、Heavy 渐进加载、全局和项目规则自动载入、运行配置面板、动态 MCP、ACP 及无额外控制台安装链路。本版不新增后台自主 Agent、模型循环、自动上下文压缩或完整仓库沙箱。

| 平台 | 安装包 | 离线载荷 |
| --- | --- | --- |
| Windows x64 | `AgentDockSetup-amd64.exe` | `agentdock_windows_amd64.zip` |
| Windows ARM64 | `AgentDockSetup-arm64.exe` | `agentdock_windows_arm64.zip` |

安装包、载荷和 `install.ps1` 均附带 SHA256 校验文件。Windows WSL 功能所需辅助文件随载荷提供，不作为独立 Linux 发行版。

AgentDock 本次按未签名构建发布，Windows 可能显示未知发布者或 SmartScreen 提示。附带的官方 cloudflared 仍须通过 Authenticode 校验；缺少 AgentDock 签名不会跳过测试与载荷校验。

## 验证与使用边界

Windows 发布流程运行全量 Go 测试、vet、安装器契约、独立 WPF HTTP/SSE/缩放回归、真实 Core 的任务与线程恢复测试，以及 Tailscale 和 Cloudflare 生命周期测试。任务事件层另有并发/race、损坏恢复、输出上限、凭据脱敏、工作区越界及旧任务回归。

桌面缩放验证采用实际 WPF 离屏渲染。Tailscale 生命周期测试使用真实 Core 配合隔离 Fake Tailscale，不能替代用户账号下的公网 DNS、证书和 Windows 重启实测。ARM64 完成构建与载荷校验，未在 ARM64 硬件上运行。本次开发验证不覆盖安装运行中的用户 AgentDock，也不强制重启 Windows。

操作说明见 [任务活动中心](../task-activity.md) 与 [Tailscale Funnel](../tailscale-funnel.md)。
