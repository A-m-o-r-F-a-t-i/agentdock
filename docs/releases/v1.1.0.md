# AgentDock 1.1.0 — Windows Tailscale Funnel

本发行版仅面向 `A-m-o-r-F-a-t-i/agentdock` 的 Windows 用户，不向上游仓库提交或发布，不生成 Linux、macOS 或容器发行资产。

## 新增与修复

- Windows 公网访问增加 Tailscale Funnel，自动读取设备域名，不需要 Tunnel Token，保留原 Cloudflare Quick/Named 与仅本机方式。
- 完整 Origin 转发与就绪验证覆盖 OAuth Metadata、MCP描述、401 challenge 和认证 initialize，管理接口的认证策略保持不变。
- 控制面板增加客户端、设备、域名、密钥到期、Funnel 状态与检测/启停入口。Tailscale 模式隐藏 Tunnel Token，托盘读取有效 provider 的公网地址，临时地址重建仅对 Quick 模式开放。
- 使用精确路径和所有权记录管理映射，拒绝覆盖其他服务或把私有 Serve 路径顺带公开，失败时恢复自身配置和原运行状态。
- 安装升级和 repair 保留 Tailscale provider、Origin、映射记录及监听端口，卸载保留 Tailscale 客户端和其他映射。
- 保留1.0.1的标准插件、Heavy 渐进加载、规则自动载入、运行配置面板及无控制台安装启动链路。

## 安装包与签名

Windows x64 使用 `AgentDockSetup-amd64.exe`，Windows ARM64 使用 `AgentDockSetup-arm64.exe`。对应 ZIP 为离线载荷，所有资产附带 SHA256 文件。安装包保留 Windows 的 WSL 功能所需辅助载荷，这些辅助程序不构成独立 Linux 发行版。

当前个人仓库未配置 AgentDock Authenticode 签名证书，本次 AgentDock 安装包与程序按未签名构建明确发布，Windows 可能显示未知发布者或 SmartScreen 提示。附带的官方 cloudflared 仍必须通过原有签名校验。缺少签名不会跳过源码测试、载荷校验或安装器验证。

## 验证边界

自动测试包含模型兼容、映射冲突与回滚、真实 Core 加 Fake Tailscale 的 HTTP/MCP/OAuth/签名下载链路、Windows GUI 构建和安装生命周期。真实 Tailscale1.102.4已验证精确根路径删除保留同端口其他映射。Fake 测试不代替真实公网 DNS、证书和 Windows 重启后的恢复验证。

本次不覆盖运行中的用户 AgentDock，也不为测试强制重启 Windows。ARM64资产在构建阶段验证，未使用 ARM64 硬件运行。配置和恢复步骤见 [Tailscale Funnel](../tailscale-funnel.md)。
