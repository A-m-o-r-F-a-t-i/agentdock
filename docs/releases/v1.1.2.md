# AgentDock 1.1.2：任务与执行中心

状态：开发候选。正式发布条件以 `v1.1.2-acceptance.json` 为准，当前未放行。

## 产品变化

增加对话和任务两种执行视图。没有 Task 的读取、搜索、目录、命令和动态 MCP 调用也可查看；存在当前任务时显示进度、当前步骤和下一动作。任务跨对话接续，任务分支与宿主对话独立。

每次调用具有服务端 CallID。命令输出持续更新同一卡片，内部 MCP 调用形成可展开的父子关系。参数错误、权限拒绝、待审批和启动失败均保留记录。任务 checkpoint 独立显示为进度里程碑。

保留并完善任务右键管理、冻结选择的批量操作、标签/状态/工作区分类、归档、回收站、待处理、搜索、通知和断线恢复。运行及待审批调用阻止危险的管理删除；源码、工作区和产物不随任务删除。

## 自动归属修订

撤销未发布开发稿中“在全部 Tool Schema 增加 conversation_id，并要求模型每次填写”的设计。普通工具只传业务参数，对话归属由接入层解析，任务和线程由 ConversationState 自动继承。

创建、恢复或显式设为当前任务只需一次绑定。查看任务和切换列表不改变执行绑定，正在运行或等待审批的调用保留启动快照。完成、取消或解绑后，新临时调用不继续归入已结束任务。

可信宿主元数据映射为本地 conv 标识。MCP 传输 Session 不直接视为对话；无法确认来源时进入明确的来源未识别分组，不要求补 ID，不根据工作区或最近调用猜测。

## 权限与可靠性

支持只读检查、按规则审批和本地明确范围内的完全权限。显式禁止规则在完全权限模式下仍生效。审批固定 Call、参数、工作区及 MCP 目标；配置变化使旧请求过期，重复批准和刷新不重复执行。

旧记录继续可读。可靠的旧命令会话只读聚合，歧义记录单独保留，损坏日志行不会阻断后续健康记录。读取旧数据不改写原始日志。
